00

Calibrate evidence

Fit conservative weights and Tq scales to known-present controls.

Known nodes and edges are positive controls, not a complete truth set: unknown hypotheses are not called absent. Node settings are fitted first; node selection is rerun with them; edge settings are then fitted independently on the resulting graph. One quadratic “rubber-band” penalty keeps weights near 1 and Tq/reference multipliers near their preferred values. Tq is optimized on a log scale. The phosphoproteomic preference defaults to 0.10 (never zero); derived scaffold closure remains fixed.

01

Select nodes

Choose evidence that establishes the signaling universe.

Each protein is an independent present-versus-absent hypothesis. The objective default assigns prior probability 0.50 to every protein; weighted Bayes factors update its odds without normalization across proteins. The optional nondetection rule assigns one configurable BF below 1 whenever an enabled dataset could assess a protein but did not observe it. Repeated nondetections multiply the odds downward; out-of-scope nodes remain neutral (for example, non-kinases in the kinase-activity stream). A protein is selected when its posterior is strictly above the selection cutoff. Tq × scales each dataset's stored empirical threshold. Newly selected candidates beyond the validated 891-node seed are inserted after their missing unordered pairs are characterized and cached. Kinase activity and phosphoprotein response share the PKA-KO phosphoproteomic source. The CCD/OMCD/IMCD streams are separately selectable, but the three streams within each assay share one experimental source; they are off in the generic default profile.

02

Characterize edges

Combine selected pairwise Bayes factors as undirected evidence.

Localization and motif streams scale their node- or site-specific Tq values. STRING and STITCH use Ref × because their normalizations use reference odds. The optional negative-evidence rule applies the selected BF below 1 only when a source could assess both endpoints but has no non-neutral relationship: missing assay coverage stays neutral. Each eligible absence is a separate update, so repeated unsupported observations can push an edge toward zero. Scaffold closure remains positive-only because failure to share a strong scaffold is not an independent nondetection. Cached raw evidence is rescored when controls change.

03

Find paths

Extend the graph to a target and rank supported routes.

Allowed intermediate ontology roles

Select which node annotations qualify a protein or molecule to relay a path.

Ontology directionality removes a reverse traversal only when one conservative role rule supports a unique direction; no-rule and conflicting multi-role pairs remain traversable both ways. This changes path traversal, not the Bayesian edge probability. The sensitivity-oriented relay default includes ligand, binding, generic signaling-process, catalytic, regulatory, and second-messenger roles. Adaptor/scaffold is available but off by default. Endpoints are always exempt. Up to 500 paths can be requested.

04

Validate temporal order

Compare proposed path order with the dDAVP phosphoproteomic time course.

This optional layer uses replicate log2(dDAVP/vehicle) trajectories at 1, 2, 5, and 15 minutes. It selects one phosphosite per gene by moderated signal-to-noise, propagates response-time uncertainty, and reports soft precedence plus a Monte-Carlo Kendall interval. The default multiple-testing correction accounts for searching across a gene's sites and timepoints. Temporal evidence never changes edge probabilities or the primary Bayesian path rank.
