01

Select nodes

Choose evidence that establishes the signaling universe.

Each protein is an independent present-versus-absent hypothesis. The objective default assigns prior probability 0.50 to every protein; weighted Bayes factors update its odds without normalization across proteins. A protein is selected when its posterior is strictly above the selection cutoff. Tq × scales each dataset's stored empirical threshold. Newly selected candidates beyond the validated 891-node seed are inserted after their missing unordered pairs are characterized and cached. Kinase activity and phosphoprotein response share the PKA-KO phosphoproteomic source. The CCD/OMCD/IMCD streams are separately selectable, but the three streams within each assay share one experimental source; they are off in the generic default profile.

02

Characterize edges

Combine selected pairwise Bayes factors as undirected evidence.

Localization and motif streams scale their node- or site-specific Tq values. STRING and STITCH use Ref × because their normalizations use reference odds. Optional scaffold closure applies one fixed likelihood when both proteins have an edge above Anchor to the same annotated scaffold; it has no degree penalty or empirical Tq. Cached raw evidence is rescored when controls change.

03

Find paths

Extend the graph to a target and rank supported routes.

Allowed intermediate ontology roles

Select which node annotations qualify a protein or molecule to relay a path.

The sensitivity-oriented default includes ligand, binding, generic signaling-process, catalytic, regulatory, and second-messenger roles. Adaptor/scaffold is available but off by default. A multi-role node is eligible when any selected role matches; the separate scaffold override excludes all scaffold-tagged intermediates. Endpoints are always exempt. Up to 500 paths can be requested.
