Calibrate evidence

Fit conservative weights and Tq scales to known-present controls.

Known nodes and edges are positive controls, not a complete truth set: unknown hypotheses are not called absent. Node settings are fitted first; node selection is rerun with them; edge settings are then fitted independently on the resulting graph. One quadratic “rubber-band” penalty keeps weights near 1 and Tq/reference multipliers near the per-dataset Preferred Tq/Ref × values shown on the evidence cards below. Tq/reference scales are optimized on a log scale. Preferred values must remain positive; derived scaffold closure has no Tq/reference scale and remains fixed.

01

Select nodes

Choose evidence that establishes the signaling universe.

Each protein is an independent present-versus-absent hypothesis. The objective default assigns prior probability 0.50 to every protein; weighted Bayes factors update its odds without normalization across proteins. Two negative-evidence mechanisms are available. The stage-wide fixed rule assigns one configured BF below 1 to each eligible nondetection. Alternatively, “Allow continuous negative evidence” can be enabled on individual datasets: it supersedes the fixed rule for that dataset, removes the historical 0.5 likelihood floor, scores weak observed values below BF=1, and represents eligible nondetections as x=0 (limited by the continuous-mode BF floor). Tq stays the positive empirical scale; zeros are evaluated against it rather than used to create a potentially zero Tq. Out-of-scope nodes remain neutral—for example, non-kinases in the kinase-activity stream. A protein is selected when its posterior is strictly above the selection cutoff. Tq × scales each dataset's stored empirical threshold. Newly selected candidates beyond the validated 891-node seed are inserted after their missing unordered pairs are characterized and cached. Kinase activity and phosphoprotein response share the PKA-KO phosphoproteomic source. The CCD/OMCD/IMCD streams are separately selectable, but the three streams within each assay share one experimental source; all six collecting-duct streams are enabled in the Version 1 profile.

02

Characterize edges

Combine selected pairwise Bayes factors as undirected evidence.

Localization and motif streams scale their node- or site-specific Tq values. STRING and STITCH use Ref × because their normalizations use reference odds. The stage-wide fixed negative-evidence rule applies one selected BF below 1 when a source could assess both endpoints but has no relationship. The per-dataset continuous alternative supersedes that rule for its dataset, retains low measured similarities, motif scores, curation effort, STRING scores, and STITCH scores as BF<1, and treats eligible no-record pairs as x=0 at the numerical floor. Missing assay coverage stays neutral. Scaffold closure remains positive-only because failure to share a strong scaffold is not an independent quantitative observation. Cached raw evidence is rescored when controls change.

03

Describe the full graph

Compute network statistics without drawing the complete graph.

Statistics to compute

The full graph is an undirected unique-pair graph containing every selected node and every edge whose posterior is strictly above this cutoff. Edge posterior remains a weight; weighted shortest-path statistics use reliability distance −ln(p). These are descriptive features of the inferred graph, not additional Bayesian evidence and not proof of causality.

04

Find paths

Extend the graph to a target and rank supported routes.

Allowed intermediate ontology roles

Select which node annotations qualify a protein or molecule to relay a path.

The default primary score is the geometric mean of edge posteriors. The optional node-aware score uses the geometric mean of every edge posterior and every internal-node posterior; fixed query endpoints are excluded, and curated/unscored molecules contribute a neutral multiplicative value of 1 rather than being treated as negative evidence. The directionality layer applies established ontology-role restrictions first. For edges positively supported by the selected KinasePredictor stream, the predicted kinase→substrate relationship is applied next. OmniPath source→target records can add a unique direction only where both earlier layers left a pair unresolved. Later sources cannot reopen or reverse an earlier disallowed traversal; disagreements and bidirectional records are audited. A disallowed reverse traversal is set to zero for path search, so a proposed linear route cannot pass through a fork or collider by walking against an established arrow. This changes path traversal, not the Bayesian edge probability or activation/inhibition sign. Endpoints are always exempt. Up to 2,000 exact ranked paths can be requested.

05

Validate temporal order

Compare proposed path order with the dDAVP phosphoproteomic time course.

This optional layer uses replicate log2(dDAVP/vehicle) trajectories at 1, 2, 5, and 15 minutes. It selects one phosphosite per gene by moderated signal-to-noise, propagates response-time uncertainty, and reports soft precedence plus a Monte-Carlo Kendall interval. The default multiple-testing correction accounts for searching across a gene's sites and timepoints. Temporal evidence never changes edge probabilities or the primary Bayesian path rank.
